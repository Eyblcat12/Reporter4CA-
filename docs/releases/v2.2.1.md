# Reporter Pro v2.2.1 — Release Provenance Fix

`v2.2.1` là bản vá metadata phát hành cho baseline local/team `v2.2.0`. Chức năng,
template chuyên biệt Full/Server/Client, golden DOCX và kết quả benchmark không đổi.

## Sửa lỗi

- Windows prebuilt bundle giờ ghi commit SHA mà annotated tag trỏ tới, thay vì ghi
  object ID nội bộ của tag.
- Manifest có thể đối chiếu trực tiếp với GitHub Actions `head_sha`, source tag và
  commit trên nhánh `main`.

## Cài đặt

```powershell
git clone https://github.com/Eyblcat12/Reporter4CA-.git
cd Reporter4CA-
git checkout v2.2.1
.\setup.bat
.\start.bat
```

Người dùng Windows muốn bỏ yêu cầu Node/npm có thể tải
`reporter-pro-v2.2.1-windows-prebuilt.zip`, sau đó đối chiếu với
`SHA256SUMS.txt` và chạy `setup-prebuilt.bat`.
