# Reporter Pro v2.1.0 — Local/Team Baseline

`v2.1.0` là baseline phát hành tái lập đầu tiên sau khi hoàn thiện workflow
local/team. Phiên bản tập trung bảo vệ dữ liệu, rút ngắn Preview và bảo đảm người
khác có thể clone, cài và kiểm thử cùng một dependency graph.

## Điểm nổi bật

- Preview Job và Preview Cache bật mặc định, có progress/cancel, chống stale race,
  artifact integrity và compatibility fallback.
- Preview `full/50` đạt 10/10 trial dưới 10 giây: P50 6,300 giây, P95 7,883 giây.
- Workspace restore kiểm tra manifest, SHA-256, SQLite, DOCX và tự rollback nếu
  database hoặc template không thể khôi phục hoàn chỉnh.
- Dependency Python trực tiếp/gián tiếp được khóa kèm hash; setup và CI dùng
  `--require-hashes`.
- Report engine giữ đủ 30/30 asset và 8/8 finding trên fixture tracking chuẩn;
  fixture đa dạng 50 máy cũng qua semantic integrity.

## Cài đặt

```powershell
git clone https://github.com/Eyblcat12/Reporter4CA-.git
cd Reporter4CA-
git checkout v2.1.0
.\setup.bat
.\start.bat
```

## Nâng cấp và rollback

1. Tạo Workspace Backup trên phiên bản đang dùng.
2. Checkout `v2.1.0`, chạy lại `setup.bat`, sau đó mở tool và kiểm tra `/api/health`.
3. Nếu Preview Job không phù hợp môi trường, đặt
   `AUTO_REPORT_PREVIEW_JOBS=0` và `AUTO_REPORT_PREVIEW_CACHE=0` trong `.env`.
4. Nếu cần quay lại source cũ, checkout tag trước đó và restore backup tương ứng.

Không dùng backup được tạo bởi phiên bản schema mới hơn trên source cũ nếu màn
dry-run báo không tương thích.

## Xác minh artifact

Release đính kèm source ZIP, TAR.GZ và `SHA256SUMS.txt`. Trên PowerShell:

```powershell
Get-FileHash .\reporter-pro-v2.1.0-source.zip -Algorithm SHA256
```

Giá trị phải trùng dòng tương ứng trong `SHA256SUMS.txt` trước khi giải nén.
