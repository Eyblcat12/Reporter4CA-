# Reporter Pro v2.1.1 — Release Pipeline Patch

`v2.1.1` giữ nguyên chức năng và dữ liệu của baseline `v2.1.0`, đồng thời sửa quy
trình phát hành để từng quality gate có trạng thái độc lập, dễ kiểm tra và rollback.

## Thay đổi

- Backend regression, frontend component test và frontend production build chạy ở
  ba bước riêng biệt trên GitHub Actions.
- Metadata Semantic Version, source archive và SHA-256 checksum tiếp tục được kiểm
  tra trước khi GitHub Release được công bố.
- Preview Job và Preview Cache vẫn bật mặc định theo kết quả benchmark 10 lượt:
  P50 6,300 giây, P95 7,883 giây và 10/10 lượt dưới ngưỡng 10 giây.

## Cài đặt

```powershell
git clone https://github.com/Eyblcat12/Reporter4CA-.git
cd Reporter4CA-
git checkout v2.1.1
.\setup.bat
.\start.bat
```

## Xác minh artifact

Release đính kèm source ZIP, TAR.GZ và `SHA256SUMS.txt`. So sánh kết quả:

```powershell
Get-FileHash .\reporter-pro-v2.1.1-source.zip -Algorithm SHA256
```

với dòng tương ứng trong `SHA256SUMS.txt` trước khi giải nén.
