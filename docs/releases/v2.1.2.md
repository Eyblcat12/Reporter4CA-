# Reporter Pro v2.1.2 — Reproducible Fixture Baseline

`v2.1.2` là baseline phát hành local/team đã sửa tính tái lập của fixture benchmark
trên Windows. Chức năng Reporter Pro và số liệu Preview không thay đổi so với
`v2.1.0`; bản vá chỉ khóa biểu diễn byte của tệp CSV khi checkout.

## Thay đổi

- Tất cả CSV trong source được checkout với line ending LF trên Windows, Linux và
  macOS.
- Fixture benchmark sinh lại vẫn khớp byte và SHA-256 với bản đã commit.
- Backend regression, frontend component test và production build có gate riêng
  trước khi tạo source archive và `SHA256SUMS.txt`.

## Baseline Preview

- 10 lượt prewarmed, fixture `Tracking_2.csv`, report type `full`, 50 assets.
- Preview P50: 6,300 giây; P95: 7,883 giây.
- 10/10 lượt giữ toàn vẹn và dưới mục tiêu 10 giây.
- Preview Job và Preview Cache bật mặc định; có thể rollback bằng environment flags.

## Cài đặt

```powershell
git clone https://github.com/Eyblcat12/Reporter4CA-.git
cd Reporter4CA-
git checkout v2.1.2
.\setup.bat
.\start.bat
```

Đối chiếu source archive tải về với `SHA256SUMS.txt` trước khi giải nén.
