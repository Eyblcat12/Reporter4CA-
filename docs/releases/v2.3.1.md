# Reporter Pro v2.3.1 — Verified Windows release

This is the downloadable release of the evidence and Studio recovery fixes
described in [v2.3.0 notes](v2.3.0.md). The v2.3.0 candidate was not published:
Windows checkout converted CSS/MJS line endings, causing its format gate to fail.
This release enforces LF for those files and tests frontend quality on both
Windows and Linux. No verification step is bypassed.

## Cài đặt trên Windows

Tải `reporter-pro-v2.3.1-windows-prebuilt.zip` và `SHA256SUMS.txt` từ Release này,
kiểm tra SHA-256, giải nén, chạy `setup-prebuilt.bat`, sau đó `start.bat`.
Khuyến nghị Python Windows 3.12; gói prebuilt không cần Node/npm.

Hướng dẫn nâng cấp, backup v1/v2 và phạm vi local một backend được giữ như
[ghi chú v2.3.0](v2.3.0.md); dùng gói v2.3.1 thay cho tên file v2.3.0 trong hướng dẫn.

Các sửa lỗi gồm giữ IoC có cấu trúc, xử lý URL an toàn, xuất IoC trong Full/Technical,
backup/rollback đầy đủ Studio và dependency dev đã vá. Nội dung phân tích điều tra
và template khách hàng vẫn cần analyst duyệt trước khi gửi báo cáo.

Các kiểm tra runtime đã có trong [hồ sơ nghiệm thu](../RELEASE_ACCEPTANCE_2026-10-06.md).
Workflow của tag v2.3.1 chạy lại backend, frontend, browser với API thật, cài source
sạch và checksum trước khi công bố gói tải xuống.
