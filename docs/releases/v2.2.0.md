# Reporter Pro v2.2.0 — Local/Team Reliability Baseline

`v2.2.0` hoàn thiện baseline dành cho cá nhân và team nhỏ: workflow chính có khả
năng tự phục hồi tốt hơn, tác vụ nền quan sát được tài nguyên, dữ liệu workspace có
backup định kỳ, migration có checkpoint/rollback và bản phát hành Windows có sẵn
production frontend.

## Điểm nổi bật

- Resource monitor hiển thị thời gian và backend RSS khi Preview/Generate; giới hạn
  RAM/timeout là opt-in để không áp một ngưỡng cứng thiếu căn cứ lên dự án khách hàng.
- Preview tự retry lỗi mạng/408/425/429/5xx tạm thời và không làm mất dữ liệu import.
- Automatic workspace backup theo chu kỳ, retention giới hạn; restore vẫn kiểm tra
  manifest/checksum, có dry-run, preview và rollback nếu phục hồi thất bại.
- SQLite tạo checkpoint có SHA-256 trước migration, chạy các bước trong một
  transaction và tự phục hồi khi lỗi.
- Windows prebuilt bundle chứa production frontend, exact Git commit và checksum;
  máy đích không cần Node/npm, nhưng vẫn cài Python dependency đã khóa hash.
- Ruff, ESLint và Prettier được bắt buộc trong local check, GitHub Actions và GitLab CI.

## Baseline báo cáo lớn

Fixture Full gồm 3.000 asset (1.200 server, 1.800 client) và 2.500 finding được chạy
10 lần, mỗi lần trong fresh process trên Lenovo 82RD, Ryzen 7 6800H, RAM 16 GB:

| Chỉ số | Kết quả |
|---|---:|
| Trial đạt | 10/10 |
| Product latency P50 / P95 | 229,6 / 236,9 giây |
| Product peak RSS P50 / P95 | 2.455,3 / 2.457,5 MiB |
| Asset được kiểm tra | 3.000/3.000 ở mọi lượt |
| Finding bị thiếu | 0 |
| Worker lỗi / temp DOCX sót | 0 / 0 |

Gate ổn định là **Full 3.000 máy trên cấu hình benchmark**, không phải cam kết rằng
mọi máy hoặc mọi template đều có cùng giới hạn. Resource monitor cần được quan sát
với dữ liệu thực tế. Mốc 3.750 máy mới là một lần chạy thăm dò, chưa phải SLA.

## Tính tương thích và rollback

- Không thay đổi các template chuyên biệt Full, Server và Client; structural golden
  của sáu report type vẫn là release gate.
- Compact DOCX path có thể tắt bằng `AUTO_REPORT_COMPACT_PROTOTYPE=0`.
- Preview Job và cache có thể rollback bằng các compatibility flag trong `.env.example`.
- Resource hard limit mặc định tắt (`0`); chỉ bật sau khi đo trên workstation đích.
- Backup tự động chỉ quản lý archive mang namespace riêng, không xóa backup thủ công.

## Cài đặt

### Từ source

```powershell
git clone https://github.com/Eyblcat12/Reporter4CA-.git
cd Reporter4CA-
git checkout v2.2.0
.\setup.bat
.\start.bat
```

### Windows prebuilt bundle

Tải `reporter-pro-v2.2.0-windows-prebuilt.zip`, kiểm tra SHA-256 trong
`SHA256SUMS.txt`, giải nén và chạy `setup-prebuilt.bat`. Bundle bỏ yêu cầu Node/npm
trên máy đích nhưng không phải installer offline hoàn toàn.

## Trước khi nâng cấp

Tạo một workspace backup thủ công và giữ bản sao ngoài thư mục ứng dụng. Không sửa
hoặc thay thế template khách hàng nếu không có yêu cầu nghiệp vụ và golden tương ứng.
