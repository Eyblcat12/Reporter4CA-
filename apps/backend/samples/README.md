# Sample Inputs

- `input.json`: minimal JSON payload used by the API sample endpoint.
- `BAO_CAO_TOOL.xlsx`: sample Excel report used by parser checks.
- `Tracking.csv`: tracking workbook fixture used by import tests. The original
  extension is retained even though the file contains an Excel workbook.
- `Tracking_2.csv`: UTF-8 CSV fixture with 50 assets (22 servers, 28 clients),
  six result states and diverse clean, malware, proxy/tunneling, suspicious,
  approved-tool and incomplete-collection notes.
